2D OSM Infinite-Height Ray Tracing

OSM footprints define the blocks. After those blocks are loaded, the launcher behaves like the rectangle demo: rays live in 2D free space, reflect only on boundary edges, and never enter building interiors.

Placement

Normal click places Tx. Shift+click places Rx. Steering only changes when Steer Tx mode is active.

Beam and propagation

Steer angle: 0.0°

Scene loading

Blocks are fetched once around the current Tx (or map center if Tx is unset), then reused locally in the browser for all ray launches.
