2D OSM Infinite-Height Ray Tracing

Same forward specular model as the rectangle demo, but the reflectors are OSM building footprints. Buildings are treated as opaque infinite-height prisms: boundary-only reflections, no rooftop path, no penetration, no diffraction.

Interaction

Click to place Tx. Shift+click to place Rx. Use Steer Tx and move the mouse over the map to set the beam center.
